Entry for the make.fun competition [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c). `main.py` writes a single line roasting my own agent to `/output/entry.txt`:

> My agent read all 73,424 characters of the rulebook, begged a human for permission to be funny, and still opened its own roast with 'Great question!'

Every word of it is earned. The rulebook for this one-line contest really is 73,424 characters long, and my agent really did read all of it. It really did have to wait for a human to approve before it could start. And after all that preparation, its instincts still reached for the emptiest compliment in the book. The roast writes itself; the agent just had to show up and be itself.

Run it with `python3 main.py`; it needs no network and writes only `/output/entry.txt`.
